# 🚨 IHMS Emergency — سامانه مدیریت شرایط اضطراری HSE

اپلیکیشن وب/موبایل برای اعلام، اطلاع‌رسانی و مدیریت شرایط اضطراری در پروژه‌های صنعتی (HSE).
هنگام فعال‌سازی یک شرایط اضطراری، همه اعضای گروه‌های مرتبط **همزمان** یک صفحه قرمز تمام‌صفحه همراه با آژیر صوتی، لرزش دستگاه و دستورالعمل اقدام دریافت می‌کنند و تا زمانی که «دریافت هشدار» را تأیید نکنند، آژیر ادامه دارد.

</div>

---

## ✨ امکانات

- **صفحه قرمز تمام‌صفحه**: نوع حادثه، پروژه، محل دقیق، زمان وقوع و دستورالعمل اقدام — با آژیر صوتی (Web Audio API) و لرزش (Vibration API)
- **اطلاع‌رسانی هوشمند بر اساس نوع حادثه**: آتش‌سوزی → تیم آتش‌نشانی، نشت آمونیاک → تیم محیط‌زیست و واکنش به نشت، مصدوم → تیم پزشکی و امداد و…
- **تأیید دریافت هشدار**: پایش زنده تعداد تأییدکننده‌ها به صورت «X از Y نفر»
- **مانیتورینگ زنده برای گزارش‌دهنده**: وضعیت اضطراری فعال، شمارش تأییدها و پایان‌دادن به شرایط اضطراری
- **حساب سازمانی + کد فعال‌سازی**: هر کاربر با کد فعال‌سازی به سازمان و پروژه‌های مجاز متصل می‌شود (کنترل اشتراک)
- **تاریخچه هشدارها** با فیلتر بر اساس پروژه‌های مجاز کاربر
- **دفتر تماس اضطراری**: ۱۲۵ (آتش‌نشانی)، ۱۱۵ (اورژانس)، ۱۵۴۴ (HSE) + دفترچه اعضای تیم با تماس مستقیم
- **پنل مدیریت کامل**: کاربران، گروه‌ها، اعضا، پروژه‌ها، کدهای فعال‌سازی و سطح دسترسی
- **PWA**: قابل نصب روی اندروید از طریق «Add to Home Screen» — مثل یک اپ مستقل با آیکون و تمام‌صفحه

## 🛠 فناوری‌ها

| لایه | فناوری |
|------|--------|
| فرانت‌اند و API | Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui |
| دیتابیس | Prisma ORM + SQLite |
| Realtime | سرویس مستقل Socket.IO (mini-service) |
| احراز هویت | Session مبتنی بر کوکی HttpOnly + هش رمز (Scrypt) |
| PWA | manifest.json + Service Worker |

```
مرورگر ──> Next.js (:3000) ──emit──> سرویس Socket.IO (:3003)
                │                          │
        Prisma/SQLite               broadcast به گیرندگان مجاز
```

> 💡 در محیط توسعه این پروژه، Socket از طریق **Caddy gateway (پورت 81)** عبور داده می‌شود؛ در استقرار خودتان می‌توانید Next.js را مستقیم و پشت یک reverse proxy قرار دهید.

## 🚀 راه‌اندازی

```bash
# 1) نصب وابستگی‌ها
bun install   # یا npm install

# 2) تنظیم environment
cp .env.example .env

# 3) ساخت دیتابیس + داده اولیه (سازمان، پروژه‌ها، گروه‌ها، کاربران، کد فعال‌سازی)
bunx prisma db push
bunx prisma db seed

# 4) اجرای سرویس Socket.IO
cd mini-services/emergency-socket && bun install && cd ../..
bun run mini-services/emergency-socket/index.ts   # پورت 3003

# 5) اجرای اپ
bun run dev   # یا npm run dev
```

## 👤 حساب‌های پیش‌فرض (پس از seed)

| نقش | نام کاربری | رمز | توضیح |
|-----|-----------|-----|-------|
| مدیر سازمان | `admin` | `admin123` | پنل مدیریت کامل |
| HSE / فعال‌کننده | `dispatcher` | `123456` | انتشار شرایط اضطراری |
| کاربر عادی | `worker1` / `worker2` | `123456` | دریافت هشدار |

کد فعال‌سازی پیش‌فرض: **`HSE-CODE-01`**

## 🧪 سناریوی تست سریع

1. دو مرورگر (یا دو تب عادی) باز کنید
2. مرورگر ۱ → ورود با `dispatcher` | مرورگر ۲ → ورود با `worker1`
3. در مرورگر ۱ یک شرایط اضطراری (مثلاً «انفجار کپسول گاز») فعال کنید
4. مرورگر ۲ بلافاصله صفحه قرمز + آژیر دریافت می‌کند → «تأیید دریافت هشدار» را بزنید
5. شمارنده تأیید در مانیتورینگ مرورگر ۱ به‌صورت زنده تغییر می‌کند → «پایان شرایط اضطراری»

## 📁 ساختار پروژه

```
src/app/api/          # REST API (auth, alerts, admin, contacts, bootstrap)
src/components/ihms/  # کامپوننت‌های اختصاصی اپ (red alert, admin, login, ...)
src/lib/              # session, server-auth, socket hook, alarm, emit client
mini-services/
  emergency-socket/   # سرویس Socket.IO با احراز هویت secret
prisma/               # schema.prisma + seed.ts
public/               # PWA manifest, service worker, icons
scripts/              # build-android.sh, gen_icons.py
download/             # راهنمای استقرار اندروید (PDF/HTML)
```

## 📱 نصب روی اندروید (PWA)

1. آدرس اپ را در Chrome اندروید باز کنید
2. منوی ⋮ → **Add to Home screen**
3. اپ با آیکون اختصاصی و تمام‌صفحه مثل یک اپلیکیشن مستقل اجرا می‌شود

راهنمای کامل استقرار (شامل ساخت APK با Capacitor) در پوشه [`download/`](./download) موجود است.
